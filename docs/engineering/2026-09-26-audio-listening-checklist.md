limiter หลัง gain เพื่อให้ linear mode ไหว, ยอมรับ tolerance แบบปรับตาม LRA

  (เสียงพูดจริงผ่าน limiter หนักกว่าสังเคราะห์), สัญญาณรบกวนพื้นหลังห้องประชุม

  ต้นทางต้นฉบับเป็นวิดีโอประชุมส่วนตัว — เจ้าของฟังจากไฟล์ผลงานได้โดยตรง

## วิเคราะห์เชิงวัตถุก่อนฟัง (agent, 2026-09-27)

เทียบต้นทางกับผลงานทีละ sample ด้วย numpy (decode ผ่าน ffmpeg, Thai ใช้ต้นทาง trim
15–50 วิ และจัดแนว lag ด้วย cross-correlation) ไม่ใช่การฟัง — ใช้ตัดสิ่งที่วัดได้ออกไป
ให้เจ้าของฟังเฉพาะสิ่งที่ตัวเลขตอบไม่ได้

**8 track สังเคราะห์ — ผ่านเชิงวัตถุทุก track**

- gain คงที่ตลอดไฟล์ (std 0.00–0.01 dB), residual หลังหักค่า gain ≈ −125 dB
  (music-bass −58 dB, stress-hot-sine −67 dB) → เป็นการปรับระดับอย่างเดียว ไม่มี
  compression/pumping (รวม music-bass ที่ checklist ระวังเรื่องหายใจ)
- tonal balance เปลี่ยน ≤ 0.1 dB ทุกย่าน (ยกเว้น music-bass ย่าน >8 kHz −0.5 dB)
- ไม่มี click ใหม่, ความยาวตรงกันทุก sample, L/R balance เท่าเดิม
- stress-hot-sine: THD ต้นทาง = ผลงาน = −33.1 dB → tool ไม่ได้เพิ่ม distortion
  แต่เสียงหึ่งจาก clip ของต้นทางยังติดมา (tool ไม่ได้ซ่อมต้นทาง — เป็นขอบเขต V1)
- ขอบต้น/ท้ายที่ไม่เงียบ (noise-pink, music-bass, hot-sine) มีระดับเดียวกับต้นทาง
  → pop ถ้าได้ยินมาจากต้นทาง ไม่ใช่ tool

**3 track เสียงไทยจริง (`gain+limiter`) — ข้อค้นพบ**

| track | gain กลาง | limiter ทำงาน (% หน้าต่าง 100 ms) | GR สูงสุด | crest ต้นทาง→ผลงาน | ย่าน 2–8 kHz |
|---|---|---|---|---|---|
| thai-meeting-01 | +9.7 dB | 9.5% | 5.9 dB | 24.4 → 17.6 dB | +0.4 dB |
| thai-meeting-02 | +6.9 dB | 17.4% | 3.2 dB | 23.4 → 17.9 dB | −0.2 dB |
| thai-meeting-03 | +6.3 dB | 16.1% | 3.1 dB | 20.0 → 16.1 dB | +0.0 dB |

- ย่านพยัญชนะ (2–8 kHz) เปลี่ยน ≤ 0.4 dB, noise floor ยังต่ำมาก (≈ −80 dBFS)
- **limiter latency ไม่ถูกชดเชย:** ผลงาน limiter เลื่อนช้ากว่าต้นทาง 219 samples
  (≈ 5 ms = lookahead ของ `alimiter`) ต้นไฟล์เป็นศูนย์ 5 ms และท้ายต้นทาง 5 ms หายไป
  ขณะที่เส้นทาง linear lag = 0 — เล็กเกินจะได้ยิน แต่ต้องแก้ก่อนต่อกับ Video
  (A/V sync) ด้วย `alimiter=...:latency=1` หรือชดเชยเอง
- **trim ไม่มี fade:** จุดตัด trim ตกกลางเสียงพูด (ต้นทาง ณ จุดตัด −34/−37 dBFS ต้นไฟล์
  01/02 และ −24 dBFS ท้ายไฟล์ 03) → เสี่ยงคลิกเบา ๆ ที่ขอบ ควรมี micro-fade 5–10 ms

**จุดที่ต้องใช้หูตัดสิน (limiter บีบหนักสุด เวลาในไฟล์ผลงาน):**

- thai-meeting-01: 28.7 วิ (GR 6.1 dB), 25.0, 31.2 วิ
- thai-meeting-02: 3.9 วิ (GR 4.3 dB), 8.2, 23.0 วิ
- thai-meeting-03: 13.8, 15.8, 19.9 วิ (GR 3.1–3.5 dB)
- ขอบต้น/ท้ายไฟล์ทั้ง 3 (คลิกจาก trim)

ฟังว่าสระ/วรรณยุกต์และพยัญชนะต้นยังชัด ไม่ "ถูกบีบ" หรือแตก ณ จุดเหล่านี้ —
ถ้าผ่าน ที่เหลือของไฟล์ผ่านเชิงวัตถุแล้ว; ชุดสังเคราะห์ 8 track ฟังผ่าน ๆ พอ
(ตัวเลขยืนยันว่าเหมือนต้นทางทุกประการยกเว้นระดับเสียง)
